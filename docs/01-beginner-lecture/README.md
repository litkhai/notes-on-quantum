## 세션의 성격

이 과정은 **양자컴퓨팅의 이론적 원리와 산업·시장 구조를 이해하는 180분 세션 강의**다. 발표 덱(49장)의 다섯 장을 따른다.

| 시각 | 장 | 내용 |
|---:|---|---|
| 0:00 | 오프닝 | 양자컴퓨팅에 대한 네 가지 오해 |
| 0:10 | 1장 양자역학의 역사 | 양자화, 뽑기와 확률진폭, 슈뢰딩거의 고양이와 결어긋남, 벨 실험, 이중슬릿 |
| 0:40 | 2장 양자컴퓨팅이란 | Grover와 두 자리 암호, 시뮬레이터 데모, 큐비트·위상·간섭·얽힘, 샷과 오류 정정, 한계 |
| 1:33 | 휴식 | 10분 |
| 1:43 | 3장 유즈케이스 | 사용례 선별, 화학·소재(VQE·QPE), 최적화(QUBO·QAOA), 금융(QAE), 보안(Shor·PQC·QKD) |
| 2:14 | 4장 어떻게 바라볼 것인가 | 하드웨어와 오류 정정 로드맵, 추상화, 클라우드 비용, GPU의 역사, 시장 숫자 |
| 2:56 | 5장 마치며 | 조직의 준비와 세 문장 결론 |

라이브 장비, 편광판, Quirk, 코딩 실습은 필수 준비물에서 제외했다. 설명에는 정적인 회로 그림, 진폭 도식, 하드웨어 비교표와 산업 가치사슬을 사용하고, 데모는 미리 실행한 시뮬레이션 결과로 진행한다.

## 대상

- 양자역학을 처음 접하는 일반인과 비전공자
- 기술·전략·사업개발·투자·정책 관계자
- 양자컴퓨팅 기업과 시장 뉴스를 근거별로 해석하고 싶은 사람
- 조직에서 양자 준비 활동의 우선순위를 정해야 하는 사람

## 세션이 답하는 질문

1. 큐비트와 중첩은 고전적인 확률과 무엇이 다른가? 이중슬릿과 벨 실험은 그 차이를 어떻게 보여주는가?
2. 양자컴퓨터는 어떤 방식으로 계산 횟수를 줄이는가?
3. 왜 모든 문제를 빠르게 풀지는 못하는가?
4. 초전도·포획 이온·중성원자 방식은 무엇을 경쟁하는가?
5. 물리 큐비트, 논리 큐비트와 오류 정정은 어떻게 연결되는가?
6. 양자 산업의 가치사슬과 현재 수익 모델은 무엇인가?
7. 이미 검증된 양자 우위와 기업 로드맵은 어떻게 다른가?
8. 어느 유즈케이스가 상대적으로 유망하고 무엇이 아직 불확실한가?
9. 시장 규모 전망을 어떤 조건과 한계 아래 읽어야 하는가?
10. 기업과 조직은 지금 무엇을 준비해야 하는가?

## 핵심 메시지

> 양자컴퓨터는 특정 문제의 구조를 확률진폭·위상·간섭·얽힘으로 처리하는 특수 가속기다.

> 산업은 하드웨어 회사만으로 구성되지 않는다. 부품·제어·소프트웨어·클라우드·HPC 통합·응용·보안이 함께 발전해야 시장이 열린다.

> 과학적 진전, 제품화, 고객 가치와 경제적 수익성은 서로 다른 단계다.
