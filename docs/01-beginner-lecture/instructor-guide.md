# 3시간 세션 강사용 가이드

[세션 홈](README.md) · [180분 진행표](runsheet.md) · [배경 이론](background-theory.md) · [슬라이드 구성안](slide-outline.md) · [산업·시장 브리프](industry-market-brief.md)

## 강의 목표

수강생이 다음 판단 틀을 갖게 하는 것이 목표다.

1. 양자 계산의 핵심을 중첩이 아닌 **위상·간섭·문제 구조**로 설명한다.
2. 이론적 가속, 실제 하드웨어 성능과 경제적 가치를 구분한다.
3. 하드웨어 방식과 산업 가치사슬을 하나의 시장으로 연결한다.
4. 양자 우위, 유용성, 상업적 우위를 서로 다른 이정표로 본다.
5. 기업 발표와 시장 전망의 증거 수준을 평가한다.
6. 조직이 지금 할 수 있는 준비와 아직 기다려야 할 투자를 구분한다.

## 설명 수준

- 행렬 계산보다 상태 변화와 결과 해석에 집중한다.
- 큐비트 상태식은 한 번만 보여주고 의미만 설명한다.
- Grover는 수식 증명 대신 `N → √N`, 최적 반복 횟수(후보 100개면 7회)와 오라클 비용을 설명한다.
- Shor는 `N = 15` 주기 찾기 예시와 공개키 암호 영향까지만 다룬다.
- 이중슬릿·고양이·벨 실험은 의식이나 신비가 아니라 진폭, 경로 정보, 결어긋남, 국소 숨은 변수의 배제로 설명한다.
- VQE·QPE·QAOA·QAE·BB84는 원리 한 문장과 조건 한 문장으로 설명하고, 근거는 [배경 이론](background-theory.md)에 둔다.
- 얽힘은 “전체 상태를 부분의 독립 상태로 분해할 수 없음”으로 설명한다.
- 산업 수치는 반드시 기준일과 출처를 함께 표시한다.

## 세션의 다섯 장

발표 덱의 다섯 장을 따른다. 오프닝에서 꺼낸 네 가지 오해를 각 장에서 회수한다.

### 1–2장: 원리와 한계

```text
뽑기와 확률진폭
  → 고양이와 결어긋남
  → 벨 실험과 얽힘
  → 이중슬릿과 세 원리
  → Grover와 데모
  → 큐비트·위상·간섭·얽힘
  → 샷·오류 정정
  → 양자 가속이 성립하는 조건
```

원리 파트는 후반부의 유즈케이스와 산업 주장을 판단할 최소 언어를 제공한다.

### 3–5장: 유즈케이스, 산업, 준비

```text
사용례 선별 필터
  → 화학·소재, 최적화, 금융, 보안
  → 하드웨어 방식과 오류 정정 로드맵
  → 추상화와 클라우드 비용
  → GPU의 역사로 본 가속기 채택
  → 시장 숫자와 위험
  → 조직의 준비
```

기업 이름 나열보다 **누가 어떤 병목을 해결하고 누가 비용을 지불하는지**를 설명한다.

## 권장 시간 배분

| 블록 | 시간 | 비중 |
|---|---:|---:|
| 오프닝: 네 가지 오해 | 10분 | 6% |
| 1장 양자역학의 역사 | 30분 | 17% |
| 2장 양자컴퓨팅이란 | 53분 | 29% |
| 휴식 | 10분 | 6% |
| 3장 유즈케이스 | 31분 | 17% |
| 4장 장비·추상화·비용·GPU·시장 | 42분 | 23% |
| 5장 조직의 준비와 결론 | 4분 | 2% |

사업·투자 청중이면 3장의 최적화·금융(11분)을 진행표 부록 F의 가치사슬·수익 모델로 바꾼다.

강의와 토론의 비중을 높이기 위해 정적 도식을 기본 자료로 사용한다. 데모(0:50)는 미리 실행한 시뮬레이션 결과 화면으로 진행하고, 움직임이 필요한 장면은 30초 이내의 사전 녹화 영상으로 보완한다.

## 준비물

- 49장 발표 덱과 [장표 대응표](slide-outline.md)
- 미리 실행한 [Qiskit Aer 결과](../04-simulations/results.md) 화면
- 진폭과 간섭을 보여주는 정적 3단계 그림
- 세 하드웨어 방식 비교표
- 산업 가치사슬 그림
- “검증된 결과 / 기업 목표 / 시장 전망” 3열 표
- QED-C 시장 추정치의 정의와 기준일
- 모든 기업 수치의 1차 출처

준비 범위 밖의 항목:

- 편광판이나 실험 장비
- 실시간 회로 시뮬레이터
- 클라우드 QPU 계정
- 코딩 환경과 학생 노트북

## 강의 원칙

### 이론 설명의 정확성

- 중첩 설명은 위상·간섭·측정까지 연결한다.
- 중첩은 계산 이득의 재료이며, 문제에 맞는 간섭 설계가 이득을 만든다고 설명한다.
- Grover의 제곱근 가속과 Shor의 큰 가속을 구분한다.
- 데이터 입력, 오류 정정과 고전 전후처리를 전체 비용에 포함한다.

### 시장 해석의 기준

- 공개기업 주가와 단기 밸류에이션은 강의 근거에서 분리한다.
- 기업 로드맵은 현재 성능과 분리한다.
- 시장 규모는 조사기관의 정의와 예측으로 표시한다.
- 기술 가치, 공급자 매출과 최종 사용자의 경제 가치를 구분한다.

### 회사보다 가치사슬을 먼저 가르친다

```text
부품·소재
  → QPU·제어 시스템
  → 소프트웨어·컴파일러
  → 클라우드·HPC 통합
  → 응용 솔루션·컨설팅
  → 최종 사용자
```

이후 각 위치에 대표 기업을 배치하면 회사 목록이 산업 구조로 이해된다.

## 강의 직전 업데이트

다음 항목만 강의 1주 전에 다시 확인한다.

1. QED-C의 최신 시장 매출 추정과 전망
2. 공개적으로 접근 가능한 QPU와 클라우드 가격(슬라이드 42, [Braket 가격 페이지](https://aws.amazon.com/braket/pricing/))
3. 주요 하드웨어 기업의 실제 제공 시스템
4. 오류 정정과 양자 우위의 최신 동료평가 결과
5. NIST PQC 표준과 전환 지침

## 수강생에게 남길 판단식

```text
산업적 가치
= 해결 가능한 문제의 가치
× 고전 대비 성능 차이
× 결과의 검증 가능성
× 시스템 가용성
− 전체 실행·통합·전환 비용
```

이 수식은 누락되는 요소를 막는 체크리스트로 사용한다.
